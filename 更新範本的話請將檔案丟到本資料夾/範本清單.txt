# 這個檔案控制「範本下載」畫面裡會列出哪些範本，用記事本開啟即可編輯。
# 每一行代表一個範本，格式是：顯示名稱|檔案名稱
# 「|」前面是畫面上顯示的名稱，可以自己取；「|」後面必須跟這個資料夾裡「一模一樣」的檔案名稱（含副檔名 .xlsx）。
# 開頭是 # 的行是說明文字，系統會自動忽略，您可以放心保留或刪除這些說明行。
#
# ▶ 如果只是要「更新」某個既有範本的內容（例如範本改版了）：
#    直接把新的 Excel 檔案，用「一模一樣的檔案名稱」丟進這個資料夾覆蓋舊檔即可，
#    不需要更動這個清單檔案。
#
# ▶ 如果要「新增」一個範本：
#    1. 把新的 Excel 檔案丟進這個資料夾
#    2. 在下面清單最後新增一行，格式為：顯示名稱|檔案名稱.xlsx
#    （不限 Excel，PDF 之類的檔案也可以，例如下面的「新手使用說明」）
#
# ▶ 如果要「刪除」一個範本：
#    把下面對應的那一行整行刪除即可（該 Excel 檔案留著或刪除都沒關係，只要清單裡沒有列到它，畫面上就不會出現）。
#
# 編輯完成後存檔，並照平常方式重新部署到 GitHub，所有使用者就會看到最新的範本清單。
