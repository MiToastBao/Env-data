# 環評監測資料填報小工具

一個純前端（HTML/CSS/JavaScript）小工具，用來管理多個環評計畫、輸入/匯入各類監測資料，
並匯出成符合「環境監測填寫範本」欄位格式的 Excel 檔。可直接發布在 GitHub Pages 上使用。

## v4.40（2026-08-28）本版重點

**v4.36～v4.39 都未曾發布，請直接用這一版。**

1. **同步視窗補上「取消修改（還原為 ○○）」**。原本四個選項全都預設「這一筆已經改了」，誤觸時沒有退路。
2. **按 Esc 或點視窗外面＝取消修改**（原本等同「只改這一筆」，那一格會默默留著新值）。
3. **「↩️ 復原上一步」現在涵蓋表格編輯與同步**。復原／重做本來就有，但以前只涵蓋刪除、清空、批次修改、套用座標／檢測方法；在表格裡改一格不在其中。現在一次動作＝一個復原點（改一格＋同步出去的那幾筆算同一個動作，按一次就全回去）。
4. **修正同一次編輯會開出兩個同步視窗**——視窗開啟時焦點移到按鈕上，又觸發一次詢問，第二個視窗蓋掉第一個而且已經沒有 baseline 可還原。使用者回報的「少了取消功能」正是這個症狀。

## 功能

- **計畫管理**：建立多個計畫（計畫代碼＋計畫名稱），各自獨立管理資料。
- **監測點基本資料**：每個計畫一份，欄位為計畫代碼／書件案號／書件名稱／執行現況／施工日期／
  竣工日期／營運日期／備註，可隨時進入該計畫的頁面補充或修改，匯出時會自動套用。
- **五大監測類別**：空氣品質、水質、地質、噪音、生態，各自的欄位完全對應您提供的範本
  （`空氣品質監測填寫.xlsx`、`水質檢測資料填寫.xlsx`、`地質檢測資料填寫.xlsx`、
  `噪音監測資料填寫.xlsx`、`生態調查資料填寫.xlsx`）。
- **匯入 Excel / PDF**：上傳監測結果檔案後，系統會依欄位名稱自動比對（含常見別名，如「監測地點」
  對應「採樣地點」），並提供一個「對應確認表」讓您在正式匯入前逐欄核對／修正，避免誤植。可一次選取多個檔案。
- **表格編輯**：匯入後的資料以可編輯表格呈現，可直接修改、刪除、或手動新增整列。表格左側固定顯示勾選框、刪除按鈕、「採樣地點」（各類別對應欄位不同：噪音為「監測地點」、生態為「調查地點」）以及「監測項目」欄位（各類別對應欄位不同：水質/空氣品質/地質為「檢測項目」、噪音為「音源發聲特性」、生態為「調查項目」），往右捲動查看其他欄位數值時，仍能同時對照是哪個測站、哪一個測項；表格本身高度固定、內部捲動，橫向捲軸不會被推到頁面最底部。
- **單位代碼／檢測機構代碼**：已內建您提供的《檢測單位代碼表》(161 碼) 與《檢測機構代碼表》
  (AA 及約 104 家機構)，在對應欄位輸入代碼時，會即時顯示代碼所代表的名稱（滑鼠移到欄位上即可看到）。
- **📖 單位代碼表查詢**：頁面右上角可隨時開啟完整的 161 筆單位代碼表，輸入代碼或關鍵字即可搜尋。系統自動比對單位代碼時若不夠確定（例如同一單位符號在代碼表中對應到不只一個代碼），會在匯入預覽畫面顯示提醒並列出受影響的項目，建議您到這裡查證後手動修正。
- **測站座標管理**：座標若是紙本手寫後掃描、不適合自動判讀，可用此工具依「測站＋採樣日期」分組，一次性為每一組輸入座標並套用（同一測站不同次採樣的座標可能略有不同，因此不會被混在一起套用；見下方說明）。
- **座標／日期時間同步確認**：在表格中直接修改某一筆的座標或採樣日期／時間時，若系統偵測到同一份匯入檔案、同一個測站（座標同步還會再比對同一採樣日期）還有其他資料，會跳出確認視窗詢問是否要一併同步，避免誤同步或忘記同步。
- **📦 批次匯入監測報告**：計畫頁面上方可一次選取多個檔案（可跨類別，例如同時選空氣品質、河川水、放流水、營建噪音等原始報告；也支援 PDF，會逐頁嘗試判斷），系統會自動判斷每個檔案／工作表（或頁面）屬於哪個監測類別，逐一帶您確認每個類別的測站設定與監測項目後匯入。目前噪音／水質／空氣品質／地質四類支援自動判斷（地質支援底泥／土壤等實驗室檢測報告格式）；生態無法自動判斷，請於生態分類頁面匯入「填寫完成的生態調查資料填寫.xlsx（完成版）」。各類別頁面的「匯入資料」也支援一次選取多個檔案（例如同一類別、不同月份的報告）。無論哪種方式，每個來源檔案都會被系統獨立追蹤，即使同時選取多個檔案一起匯入，也不會被誤判成同一份報告（例如同一測站不同月份的資料不會互相同步污染）。
- **監測項目勾選（兩層：預設項目＋可展開的其他項目）**：匯入資料時，系統會列出報告中偵測到的所有監測項目（不論是智慧解析或一般欄位比對匯入），讓您勾選要匯入哪些項目。清單分成兩層：上方是**一般申報實際會送出的測項**（預設勾選），下方是可展開的「➕ 其他偵測到的測項」（預設不勾選、平常收合）。例如 24 小時環境噪音報告，系統讀得到 24 筆逐時的 Leq／Lmax／L5／L10…，但預設只勾 **L日／L晚／L夜**；環境振動預設只勾日間的 **Lvd(10)** 與夜間的 **Lvn(10)**，同一份報告裡的事件振動位準(Lveq) 收在展開區。真的需要時展開勾選即可，上方的「全選／全不選」不會動到收合區（收合區有自己的一組）——不會被固定寫死成某個範本的項目數量，每個計畫案報告裡有哪些項目就會列出哪些，可依實際需求增減。項目勾選清單下方還有一個可展開的「詳細資料列表」，能逐筆勾選/排除特定資料（例如同樣是 CO 這個測項，但只想排除其中某一筆特定測站或日期的資料），不用整個測項類型一起排除。
- **時間欄位直接輸入**：時間欄位改為文字輸入（不再是容易滑動選不到的原生時間滾輪選單），可直接打「1430」「14:30」皆可，離開欄位時會自動整理成 HH:MM 格式顯示（不顯示秒數，符合官方範本本身的格式）；日期欄位同樣改為文字輸入，顯示「西元/月/日」格式（如 2026/05/12），可直接打「2026/5/12」或「2026-5-12」。內部儲存與匯出仍維持與範本相容的格式，不受顯示格式影響。
- **同批次同測站的欄位同步（都會先詢問）**：從同一份檔案匯入的資料，如果事後在表格中修正某一筆的內容，系統會跳出確認視窗，詢問是否要把「同一份檔案、同一個地點、同一採樣日期」的其他資料列一併同步更新——選「確定」才會套用，選「取消」則只修改這一筆。適用範圍是除了「採樣地點/監測地點/調查地點」（同步比對依據本身，不適用同步）與「檢測數值/監測數值」（每筆本來就該獨立）以外的所有欄位，包含座標、日期時間、檢測類別、管制標準、管制區、檢測方法、單位代碼、檢測機構、備註等。
- **🧪 檢測方法管理與跨季記憶**：依測項（如 SO2、總磷、Leq）列出目前資料中出現過的所有項目，可統一補上或修改檢測方法／單位代碼，套用到所有相同測項的資料列。系統會記住您確認過的設定（存在該計畫底下），下一次（含下一季）匯入同一計畫的資料時，若報告本身沒有提供某測項的檢測方法，會自動帶入先前記住的值；仍然缺少的話，匯入預覽畫面會列出提醒。
- **跨季測項比對（自動偵測新增測項）**：系統會記住每個測站歷史上出現過的所有測項，包括您事後手動在表格裡新增、或匯出後在 Excel 補齊完整版再重新匯入回系統學到的測項。下一次匯入同一測站時，若過去記錄裡有的測項這次報告沒出現（例如某些測項只有 PDF、系統無法自動判讀，過去是您手動建立的），匯入預覽畫面會列出提示，可勾選是否要一併新增這些測項的空白列——檢測方法、單位代碼、項目名稱都會依記憶自動帶好，只需要您手動輸入本次的檢測數值。**要讓系統學到這些測項，只要把補齊完整版的 Excel 檔案用「匯入資料」重新上傳回系統即可**（不需要另外的功能，一般匯入流程就會自動記住）——每次匯出後畫面右下角也會出現提醒，說明這個做法。
  - **比對基準是「最近一次確認匯入」，不是季別標籤**：系統並不會依照期別標籤去強制對應「上一季」，單純是記住「您最近一次確認匯入的內容」，下次匯入時用來補齊空白欄位、或提示新增遺漏的測項。一般情況下大家都是照順序（Q1→Q2→Q3…）匯入，所以看起來就像是跟前一季比對；但如果您想指定要比對某一份特定資料（例如想跳過中間幾季、直接參考更早以前的完整版），只要**先把那份資料匯入並確認，再匯入這次真正要處理的資料**，系統就會以最後確認的那份為準。匯入視窗與缺少測項的提示區塊裡都有可展開的說明可供查看。
  - **座標、方法、管制標準等其他欄位也適用同樣的機制**：不只是「有沒有這個測項」的比對，若本季報告某些欄位（如座標、管制標準、環境音量標準）沒有讀到值，只要歷史記錄裡有，系統也會自動補齊空白欄位。座標等經常需要事後透過「測站座標管理」補填的欄位，補填後也會即時更新記憶，供下一季使用。
- **匯入衝突偵測與比對**：匯入時系統會比對日期／時間／地點／測項都相同的既有資料。完全相同的資料會自動安靜忽略，不會重複詢問；若日期／時間／地點／測項相同但其他內容不同（通常代表您重新匯入了手動修正過的版本），會清楚列出「原有資料」跟「本次匯入」逐欄對照，讓您確認要套用新版本（直接更新既有資料，不會多出一筆重複）或保留原有資料——確保重新匯入完整版時，不會發生誤覆蓋或誤丟失修正的情況。
- **落塵量報告支援**：空氣品質智慧解析新增支援「落塵量」報告格式（一個測項對應多個測站的直式表格），會自動辨識並匯入。
- **匯出**：可依單一類別匯出（檔名與範本一致，例如 `E-2173_空氣品質監測填寫.xlsx`），
  也可一次匯出計畫底下所有已填寫的類別。匯出的 Excel 結構（工作表名稱、欄位順序）與您提供的
  空白範本完全一致。
- **備份／還原**：因為是純前端網站、資料存在瀏覽器裡（見下方「資料儲存方式」），
  頁面右上角提供「匯出備份」／「匯入備份」，可將所有計畫資料打包成一個 JSON 檔，
  用於換電腦、換瀏覽器，或作為資料保險。

## 資料管理（新增／刪除／批次操作）

- **計畫刪除**：進入計畫頁面後，右上角「刪除計畫」可刪除；左側計畫清單每個項目也直接有 🗑 圖示，不需要先點進去才能刪除。
- **匯入紀錄管理**：每個類別頁面上方「📜 匯入紀錄」可查看這個類別過去每一次匯入的紀錄（時間、來源檔案名稱、匯入方式、筆數），可針對單一次匯入整批刪除，不需要在表格裡一筆一筆找。（手動新增／編輯的資料不會出現在匯入紀錄裡，請用下面的批次勾選刪除。）
- **表格內多選批次刪除**：資料表格每列前方新增勾選框，表頭也有「全選」；勾選後上方會出現「刪除已選取」工具列，可一次刪除多筆，不論是匯入的還是手動輸入的資料都適用。
- **清空此類別**：類別頁面上方「🗑 清空此類別」可一次清空該類別全部資料（含匯入紀錄），用於整批重做。
- **匯出可勾選類別**：「匯出全部類別」會先跳出勾選畫面，只列出目前有資料的類別，可自行決定要匯出哪些，不一定要全部匯出。若這些類別裡有多個期別的資料，還會出現「只匯出哪一期」的選單，預設不會混雜期別，除非您主動選擇「全部期別」才會一次匯出所有季度的資料。
- **年/季期別標記與篩選**：匯入資料時，系統會依採樣日期自動猜測所屬「年/季」（如「115年第2季」），可手動確認或修改。各類別頁面上方會出現「期別」下拉選單，可切換只查看/編輯某一期的資料；「匯出此類別」也會依此篩選範圍匯出，確保匯出的檔案不會混雜其他季度的資料。
- **表格內容搜尋與 Excel 風格欄位篩選**：各類別頁面上方新增「🔍 搜尋任何欄位內容」輸入框，打關鍵字（測站名稱、測項、日期等）即可即時篩選畫面上顯示的資料列；每個欄位表頭旁也新增篩選按鈕（▾），點擊可列出該欄位所有實際出現過的值並勾選要顯示哪些，用法與 Excel 的自動篩選一致。兩者都純粹是畫面篩選，不影響匯出範圍（匯出範圍由期別篩選決定）。篩選狀態下，「全選」與批次刪除都只會作用在目前看得到的資料，不會誤動到被篩選隱藏的其他資料。
- 以上刪除操作都會有二次確認視窗，避免手滑誤刪。

## 如何更新「範本下載」清單與「環評申報網站」連結（讓所有使用者都看到最新版本）

因為本系統沒有伺服器，**應用程式裡沒有、也不會有「任何使用者上傳檔案或修改網址，就能讓所有人都看到更新」的功能**——這種功能技術上等於是把「寫入權限」開放給每一個打開網站的訪客，一旦有人（不論是惡意或誤操作）上傳了有問題的檔案或網址，所有人都會受害，這正是應該極力避免的設計。

**正確、安全的更新方式，是透過您已經在用的 GitHub 部署流程**，而且完全不需要寫程式或碰任何程式碼——只要用「記事本」就能完成。網站根目錄有兩個資料夾，光看名字就知道用途：

```
更新網址的話丟到本資料夾／
    網址.txt

更新範本的話請將檔案丟到本資料夾／
    範本清單.txt
    環境監測填寫範本115_8_18.xlsx
    噪音監測資料填寫.xlsx
    地質檢測資料填寫.xlsx
    空氣品質監測填寫.xlsx
    水質檢測資料填寫.xlsx
    生態調查資料填寫.xlsx
```

### 更新「環評申報網站」網址（所有使用者都會看到）

1. 打開「**更新網址的話丟到本資料夾**」這個資料夾，用記事本打開裡面的 `網址.txt`。
2. 把裡面的網址整個刪掉，貼上新的網址（只要網址本身，不要加其他文字），存檔。
3. 跟平常更新這個系統一樣，把整包檔案重新上傳到 GitHub 並發布。**所有使用者下次打開網站時，就會自動看到新網址**。

### 更新範本（所有使用者都會看到）

- **如果只是「更新」某個既有範本的內容**（例如環境部改版了噪音範本）：直接把新的 Excel 檔案，用「**一模一樣的檔案名稱**」丟進「更新範本的話請將檔案丟到本資料夾」覆蓋舊檔即可，**不需要改任何其他東西**。
- **如果要「新增」一個範本**：
  1. 把新的 Excel 檔案放進這個資料夾。
  2. 用記事本打開資料夾裡的 `範本清單.txt`，在最後新增一行，格式是：`顯示名稱|檔案名稱.xlsx`（中間用鍵盤上的直線符號 `|` 分隔，這個符號通常在 Enter 鍵上方那顆按鍵，需要按住 Shift）。存檔。
- **如果要「刪除」一個範本**：用記事本打開 `範本清單.txt`，把對應的那一行整行刪掉，存檔即可（Excel 檔案本身留著或刪除都沒關係，只要清單裡沒列到它，畫面上就不會出現）。
- 不管是新增、刪除還是修改，做完之後，一樣要把整包檔案重新上傳到 GitHub 並發布，才會讓所有使用者看到。

`範本清單.txt` 裡開頭是 `#` 的行是操作說明，系統會自動忽略，您可以保留當作提醒，也可以刪除。

**這兩個純文字檔案，即使打錯字或格式不對，也不會讓整個網站當掉**：網址格式錯誤時，系統會自動改用內建的預設網址；範本清單裡如果某一行漏打了 `|` 符號，那一行會被自動忽略；如果檔名打錯、資料夾裡實際上沒有那個檔案，畫面上「範本下載」清單裡對應的那一項會顯示紅色的警告文字，清楚告訴您是哪個檔案有問題，方便您回頭檢查修正。

**為什麼這樣設計最安全**：更新管道跟「這個系統本身要如何更新」完全共用同一個、已經被您控管的 GitHub 部署流程，並沒有另外開一個「任何訪客都能寫入」的後門——只有您（或您授權、能夠把檔案上傳到您 GitHub 專案的協作者）才能做這個更新。只要妥善保管 GitHub 帳號權限，這個機制就跟「這個系統的其他任何一次更新」一樣安全。若團隊裡有多人需要協作更新，建議善用 GitHub 本身的機制（例如要求 Pull Request 經過審核才能合併），而不是在應用程式裡另外開放上傳功能。

畫面上「✏️ 環評申報網站」旁邊的編輯按鈕，只會修改**您自己這個瀏覽器**看到的連結（存在您個人的電腦裡），不會影響其他使用者，也不會覆蓋 `網址.txt` 的共用設定——那是給您個人臨時調整用的，不是給所有人共用更新用的管道。

## 如何更新「常用測項」對照表（讓所有使用者都看到最新版本）

每個類別頁面新增了「☑️ 常用測項新增」按鈕，讓沒有原始報告可以匯入的全新計畫，也能直接勾選常見測項，快速建立空白資料列，系統會自動帶入對應的檢測方法與單位。這份「常用測項」清單，一樣是用純文字檔＋清楚命名的資料夾維護，做法跟前面範本／網址的更新方式一致。

網站根目錄的「更新測項單位方法對照表的話請編輯本資料夾」資料夾裡，有一個 `測項對照表.txt`，用記事本打開即可編輯，格式是每行一筆：

```
類別代碼|測項名稱|檢測方法|單位代碼
```

類別代碼對應：`air`(空氣品質) `water`(水質) `noise`(噪音，含振動、低頻噪音) `geo`(地質) `eco`(生態)。單位代碼可以用畫面上的「單位代碼表」按鈕查詢。

- **新增測項**：在對應類別區塊新增一行即可。
- **刪除測項**：把對應那一行整行刪除即可。
- **修改方法或單位**：直接編輯那一行的內容即可。
- **同一個測項有多種檢測方法**（例如水質「溶氧」可以用電極法或碘定量法，兩種方法的單位可能還不一樣）：寫兩行，測項名稱要完全一樣，方法跟單位各自填寫該方法對應的內容。使用者在畫面上勾選這個測項時，系統會自動列出這幾種方法讓使用者選，選了哪個方法，就會自動帶入該方法對應的單位。

跟範本／網址一樣，編輯完存檔後，重新部署到 GitHub，所有使用者就會自動看到最新的常用測項清單，且格式錯誤也不會弄壞網站（漏寫「|」符號的那一行會被自動忽略）。

**目前資料的完整度說明**：清單裡的項目是根據系統開發過程中實際解析驗證過的真實檢測報告與官方送件檔案建立（含 115Q1／113Q3 完整送件版本），目前涵蓋：空氣品質約 106 項（含大量 VOC 揮發性有機物）、水質 35 項（含重金屬類）、噪音／振動／低頻噪音 5 項、地質 9 項（底泥品質重金屬類）。生態依需求說明由其他人另行彙整，暫不建立。水質尚未涵蓋不同水體類型（河川／地下水／放流水）可能有的完整常見測項組合，若後續有新的監測報告，建議持續提供以便補齊，避免憑印象猜測方法代碼影響正式送件的正確性。

「☑️ 常用測項新增」視窗裡還有兩個提升效率的功能：
- **「要建立幾份」數量輸入**：例如同時勾選 10 個測項、份數填 3，會一次新增 30 筆空白資料（每個測項各自新增 3 筆），適合像「3 個測站各測同樣 10 個測項」這種情境，不需要重複開啟視窗 3 次。
- **記憶標籤**：每次成功套用勾選後，系統會自動記住這次的組合，顯示成畫面上方可點擊的標籤（例如「水溫、pH值、導電度…等5項」），下次開啟同一類別的視窗時，點一下標籤就能快速重新勾選同樣的組合（不含数量設定，數量每次仍需自行輸入），標籤旁邊的「✕」可以手動刪除；標籤記憶跨所有計畫共用（存在瀏覽器裡，非上傳到伺服器），最多保留最近 8 組。

除了這份共用清單外，**使用者也可以在「☑️ 常用測項新增」視窗裡，直接新增自己的自訂測項**（測項名稱＋方法＋單位），這筆會被記在該計畫自己的記憶裡，下次開啟這個計畫的清單時，這個自訂測項也會出現在勾選清單裡，供反覆使用——不需要每個計畫都申請新增到共用清單，也不會影響到其他人。

## 關於「自動抓取資料」的實際做法

您的原始檢測報告（華光工程顧問股份有限公司格式）並不是乾淨的表格，而是像紙本報告一樣、欄位標籤和數值散落各處的「表單」格式。針對這種真實情況，本工具內建了**表單智慧解析**功能：

- **噪音類別**：可直接辨識「固定音源噪音測定報告（營建工程，BN）」「固定音源振動測定報告（營建工程，BV）」「低頻噪音測定報告（LFN）」「環境噪音／振動 24 小時報告（N／V）」四種報告格式，自動抓取日期、時間、座標、Leq/Lmax／Leq,LF／Lvd(10)（日間）／Lvn(10)（夜間）／Lveq／Lvmax 數值、法規依據、檢測方法、檢測機構等欄位。噪音本來就有多種統計值（日／晚／夜的 Leq、Lmax、振動日間的 Lvd(10)、夜間的 Lvn(10) 與 Lveq…），系統一律全部讀出、各成一筆，以「監測時段」與「音源發聲特性」區分，再由您在匯入預覽的測項勾選清單挑選要送件的項目。
- **水質類別**：可辨識檢驗項目直式表格格式的報告，逐項抓取檢測值、偵測極限、單位、方法。
- **地質類別**：可辨識底泥／土壤等實驗室檢測報告（例如 `06525DS27` 底泥檢測報告），抓取採樣日期時間、採樣地點、檢驗項目、檢測值、偵測極限、單位、檢測方法與採樣單位。「檢測類別」（底泥品質／土壤品質／廢棄物…）刻意不自動猜測，改由您在匯入預覽的「測站設定」自行選擇，選好後套用到該測站全部資料。
- **空氣品質類別**：可辨識 24 小時連續監測報告，自動抓取報告中實際出現的所有污染物項目（SO2、NO2、NOx、NO、CO、O3、CH4、NMHC、THC、PM10，以及側表的 TSP、PM2.5，不侷限固定 7 項）的日平均值、對應單位代碼、各項目的檢測方法（讀取報告備註欄的方法對照表取得，比寫死更準確也更不容易過時）、檢測機構。系統抓到哪些項目就會全部列出，匯入時再由您勾選實際要送件的項目（見下方「監測項目勾選」說明）。（此報告格式本身不含 GPS 座標，需透過下方「測站座標管理」補充一次。）系統會直接讀取 Excel 檔案本身的「欄位隱藏」設定，判斷這個測站是否實際有監測某個污染物——因為許多檢驗室共用同一套報告範本，測站沒有裝設對應儀器的項目欄位會被設定隱藏（但儲存格裡仍留有無意義的佔位文字），系統偵測到隱藏欄位會自動略過該項目並跳出提醒，不會誤當成真實測值匯入；若欄位是可見的，則正常判讀（含合理的「低於偵測極限」讀值）。
  - **要哪一種數值？** 這類報告同一個測項會同時給出「每小時測值」「日平均值」「最大小時平均值」「最小小時平均值」「最大8小時平均值」。系統五種全部讀進來，匯入預覽會出現一個選擇區塊讓您勾選這次要匯入哪一種，**預設是「日平均值」**（一般申報用的數值）。選了日平均值以外的統計值時，檢測項目名稱會自動寫清楚（例如 `CO最大8小時平均值`），日平均值則維持簡短名稱（`CO`），避免同一天同一測站同一測項出現兩筆分不出來的資料。
  - **採樣期間的兩種寫法都支援**：有的報告有「監測時間」欄位（例如 `2/12 ~ 2/13`），有的則是把期間直寫在最左邊那一欄、一格一個字（`115／年／6／月／25／日／至／115／年／6／月／26／日`），兩種都能正確讀出日期(起)與日期(迄)。
- 上傳一個檔案（可能內含多個工作表，例如一次上傳一整份報告，內含 20～30 個測站）時，系統會**自動掃過每個工作表**，能辨識的就抓取，不能辨識的會列出來讓您知道被略過了。

**準確度**：以上三種格式都已經用您提供的實際季報告，逐欄位比對「已完成填寫版本」核對過——日期、時間、數值、單位代碼、檢測方法、檢測機構代碼皆與正式送件版本完全一致。唯一無法從報告本身取得、需要靠「測站設定」補充的，是 GPS 座標、正式站名、管制區等這類報告中本來就沒有記載的資訊。

**測站設定（重要）**：報告本身不會包含所有欄位（例如噪音報告的「監測地點」欄位常是概略描述如「Y1車站~Y4車站」，但正式送件用的是特定站名如「YC01標工區周界外」；水質與空氣品質報告則完全不含GPS座標）。因此匯入時會先顯示一個「測站設定」畫面，讓您依報告內的**測點編號**逐一補上正式站名／座標／管制區等資訊，勾選「記住此設定」後，之後同一測站的資料再匯入就會自動套用，不用每次重填。

**報告檔案裡殘留的舊工作表**：實際的季報告 Excel 常留著上一輪忘了刪除的工作表——版面一模一樣、測站名稱一樣，但「監測日期」是空白的、數值是舊的。系統會照樣讀出來，但**讀不到採樣日期的資料一律預設不勾選**，並在匯入預覽以紅框列出是哪幾張工作表；確定要用的話可以在「📋 詳細資料列表」勾選回來。

**座標為手寫掃描件時**：如果您的原始報告座標是紙本手寫後掃描的（無法可靠自動判讀），建議略過匯入時的座標欄位、直接匯入其他資料，事後在每個類別頁面上方點選「📍 測站座標管理」，畫面會依「測站＋採樣日期」列出每一組（同一測站若在不同日期採樣過，會分開列出，因為座標可能略有不同），為每一組輸入座標後按「儲存並套用」，只會套用到該測站、該採樣日期的資料列——不會影響到同一測站其他次採樣的資料。此工具在五個監測類別（空氣品質／水質／地質／噪音／生態）都可以使用，且會直接讀取／寫入目前表格中的資料，跟資料來源（匯入或手動新增）無關。全部類別的座標都補齊後，即可用「匯出全部類別」一次性匯出完整檔案。

**ND／比較關係的填寫規則**：水質類別的智慧解析已對照官方填寫範本說明與您實際送件的資料驗證過，規則如下——測值為 ND 時，「比較關係」與「檢測數值」兩欄都填 `ND`；測值為「< A」時，「比較關係」填 `<`、「檢測數值」填 A 本身的數字；不論何種情況，只要原始報告有列出偵測極限，「檢測極限」欄一律照實填入，三者互相獨立、不會因為是 ND 就漏填極限。另外，若測項本身沒有單位（例如 pH 值），「檢測濃度/質量單位」會正確填入代碼 161（無），不會留空白。

**PDF 匯入的判讀能力**：噪音／水質／空氣品質的智慧解析現在也會嘗試套用在 PDF 上（無論是各分類頁面的「匯入資料」或計畫頁面的「批次匯入」），做法是把 PDF 逐頁的文字依座標重新組成類似 Excel 儲存格的表格，再用跟 Excel 一樣的判讀邏輯去找欄位。但 PDF 終究是圖像化的版面、不是結構化資料，準確度天生低於 Excel（例如掃描歪斜、字型特殊、版面複雜時容易誤判），系統偵測到資料來自 PDF 時會在匯入預覽畫面跳出提醒，請務必逐筆核對後再匯入，尤其是數值與座標欄位。若您手上有原始 Excel 檔，仍強烈建議優先使用 Excel 匯入。

**未知報告格式的自動偵測（不再「什麼都抓不到」）**：上述解析器是針對**已知的報告版型**寫的。遇到系統沒看過的實驗室報告，不會再整份讀不到資料——系統會改用「看欄位標題找欄位」的通用方式，盡量找出下列 7 個必要欄位：

> 日期(起)、日期(迄)、時間(起)、時間(迄)、檢測項目、監測數值、檢測單位

連帶也會試著找出採樣地點、檢測方法、檢測極限、檢測機構、檢測類別。支援兩種常見版型：

1. **表單型**：報告上方是「採樣地點：…／採樣日期：…／採樣時間：…／樣品特性：…」這類標籤，下方接一張測項表格。上方標籤提供整張報告共用的日期／時間／地點，表格提供每個測項的數值／單位／方法。
2. **平表型**：每一列就是一筆測值（例如：測站｜監測日期｜監測時間｜測項｜測值｜單位｜檢測方法）。
3. **橫排型（測項名稱當欄位標題）**：噪音、振動、空品報告常見的版型——`Leq｜Lmax｜L5｜L10`、`L日｜L晚｜L夜`、`SO2｜NO2｜NOx｜CO`，名稱橫著排、數字在下面。若下方每一列的最前面是時段（`14~15`），會逐時各產生一筆並填好時間(起)(迄)；若只有一列彙整值，就產生一組。同一張工作表若有好幾個這種區塊（逐時一組、彙整一組），會分成幾組讓您選要匯入哪一組。
4. **標示式數值**：`Lv日(Lv10)= 39.2`、`Lv夜(Lveq)= 30.1` 這種散落在表單上的「名稱＝數值」。

表頭不一定要在第一列，被合併儲存格拆成兩三行（例如「偵測」「極限」分成兩行）也能辨識；表頭若是兩三列疊在一起（「時間／噪／音 dB(A)」壓在真正的「Leq｜Lmax｜L5」上面），會挑「能解釋比較多不重複測項名稱」的那一列當表頭。單位列（一整排 ppm）、佔位符號（`*`、`—`）都不會被誤認成測項。**沒有採樣日期也沒有採樣時間的工作表**（參照值表、工作表2 之類的雜項頁）一律不當成監測資料，不會被匯入。**用這種方式讀到的資料，匯入預覽會以紅框明確標示「這份不是系統內建認得的格式，以下數值是系統猜出來的」，並列出哪些欄位找到了、哪些沒找到，請務必逐筆核對後再匯入。** 搭配「先匯入上一季同一測站的資料」使用效果最好：座標、檢測方法、單位代碼等不會逐季改變的欄位會自動沿用，這次只需確認日期／時間／數值。

**生態類別（重要）**：生態調查通常由其他公司負責填報，本工具**只能匯入「已填寫完成」的 `生態調查資料填寫.xlsx`（完成版）做資料彙整，無法判讀生態監測／調查報告原始檔**。生態分頁上方與匯入視窗都會顯示這項提示；若選到的檔案看起來不是完成版，系統會先提醒再讓您決定是否繼續（仍可自行對應欄位）。空白的生態範本可照常從右上角「📥 範本下載」取得。

**日期與時間怎麼判讀、怎麼顯示**：全站的日期／時間換算集中在 `js/datetime.js` 一份程式處理，不受電腦時區影響（已在台北、UTC、洛杉磯、吉里巴斯四種時區實測結果一致）。可讀入民國年（`115年06月25日`、`115.06.25`、`115/6/25`、`1150625`）、西元年（`2026-06-25`、`2026/6/25`、`20260625`）、Excel 原生日期儲存格與序列值，以及 `12時00分`、`2:30 PM`、`0830` 等寫法。畫面上**日期一律只顯示 `西元/月/日`（例如 2026/06/25），時間一律只顯示 `時:分`（例如 08:30），不會出現「秒」**；匯出的 Excel 也是真正的日期／時間儲存格，格式分別為 `yyyy/mm/dd` 與 `h:mm`。

一般 Excel 欄位比對匯入的運作方式：

1. **自動比對**：以欄位名稱做比對（完全相同 → 常見別名 → 部分包含），盡量猜出對應關係。
2. **人工確認**：匯入前一定會出現「對應確認表」，列出目標欄位（如「檢測數值」）目前對應到您
   檔案中的哪一欄，您可以用下拉選單修正錯誤的對應、或設定「不匯入」。
3. 確認後才會把資料寫入表格，且**都還可以在表格中手動再次修改**。

PDF 匯入是「輔助功能」：程式會嘗試從 PDF 文字座標重建表格列，但掃描版 PDF、複雜排版
的表格準確度會明顯較低，**強烈建議優先使用 Excel/CSV 格式匯入**，PDF 僅作為備用。

## 如何發布到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `env-monitoring-tool`）。
2. 把這個資料夾（`index.html`、`css/`、`js/`）裡的所有檔案上傳到 repository 的根目錄
   （或 `docs/` 資料夾，兩種都可以，只要等一下設定對應）。
3. 到 repository 的 **Settings → Pages**：
   - Source 選擁「Deploy from a branch」
   - Branch 選 `main`（或您的預設分支），資料夾選 `/ (root)`（或您放檔案的 `docs/`）
   - 儲存後，GitHub 會給您一個網址，例如 `https://你的帳號.github.io/env-monitoring-tool/`
4. 等 1-2 分鐘部署完成後，開啟該網址即可使用。

> 小提醒：本工具用到的兩個外部函式庫（Excel 讀寫用的 SheetJS、PDF 讀取用的 pdf.js）是透過
> `index.html` 裡的 CDN 連結載入，開啟網頁時需要能連上網路（`cdnjs.cloudflare.com`）。

## 檔案結構

```
index.html          主頁面
css/style.css        樣式
js/version.js        版本號與更新紀錄
js/schema.js         五大類別＋基本資料的欄位定義（對應您的範本欄位）
js/codes.js          內建的單位代碼表／檢測機構代碼表
js/storage.js        資料存取層（封裝 localStorage，含測站設定）
使用說明.html        新手使用說明（獨立頁面，右上角按鈕開啟；可列印成 PDF）
js/datetime.js       日期／時間的唯一換算來源（讀入、儲存、顯示格式）
js/import.js         一般 Excel/CSV/PDF 欄位比對匯入邏輯（含表頭列自動偵測）
js/autodetect.js     未知報告格式的通用偵測（依欄位標題找出必要的 7 個欄位）
js/smartparse.js     噪音／水質／空氣品質／地質原始報告的表單智慧解析邏輯
js/export.js         匯出 Excel（比照範本結構）
js/app.js            介面互動邏輯（計畫管理、分頁、表格、匯入/匯出彈窗）
```

  - 校對欄位對應別名表，讓自動比對更準；
