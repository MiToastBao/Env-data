# 這個檔案控制「☑️ 常用測項新增」功能裡，各類別可以勾選的測項清單，用記事本開啟即可編輯。
# 每一行代表「一個測項的其中一種檢測方法」，格式是：類別|測項名稱|檢測方法|單位代碼
#   類別代碼：air(空氣品質) water(水質) noise(噪音) geo(地質) eco(生態)
#   單位代碼請對照系統內建的「單位代碼表」按鈕查詢；沒有單位／方法的欄位可以留空，但前後的「|」都要保留。
# 開頭是 # 的行是說明文字，系統會自動忽略。
#
# ▶ 同一個測項如果有「兩種以上」檢測方法（例如溶氧可以用電極法或碘定量法），
#    就寫兩行，測項名稱要完全一樣、方法跟單位各自填寫該方法對應的內容。
#    使用者在畫面上勾選這個測項時，系統會自動列出這幾種方法讓使用者選。
#
# ▶ 新增測項：直接在對應類別區塊新增一行即可。
# ▶ 刪除測項：把對應那一行整行刪除即可。
# ▶ 修改測項的方法或單位：直接編輯那一行的內容即可。
#
# 編輯完成後存檔，並照平常方式重新部署到 GitHub，所有使用者就會看到最新的測項清單。
#
